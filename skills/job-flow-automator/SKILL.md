## 🎯 What is Job-Flow Automator?

Job-Flow Automator is an end-to-end Python & Typst career automation tool comprising:
1. **Multi-Source Scraper (`main.py`, `custom_boards.py`):** Aggregates jobs from LinkedIn, Indeed, VC Portfolios (AshbyHQ, Greenhouse), Arbeitnow, and Berlin Startup Jobs RSS with zero API cost.
2. **Language & Title Filter (`config.py`):** Regex-based exclusion of local language constraints (German, Spanish, French) and seniority/tech role title exclusions.
3. **Cumulative Review Tracker (`filter_reviewed.py`):** Cross-spreadsheet duplicate exclusion matching by both clean URLs and normalized `(Title, Company)` pairs.
4. **Streamlit Control Dashboard (`app.py`):** 1-click external link opening, 🟡 *Reject* / 🔵 *Apply* tracking, and instant resume tailoring.
5. **AI ATS Resume Tailor & Typst Compiler (`prompt.md`, `main.typ`, `tailored.typ`):** Interactive 2-phase Gemini alignment generating pixel-perfect 1-page A4 PDFs in under 150ms via Typst CLI.

## 🛠️ Operational Guide for AI Assistants

### 1. Helping the User Run the Application
- **Web Dashboard:** Run `streamlit run app.py` (or execute `Run_JobFlow.bat`).
- **CLI Scraper Only:** Run `python main.py` (outputs `jobs_clean_YYYY-MM-DD_HH-MM.csv`).
- **CLI Review Filter:** Run `python filter_reviewed.py` (scans all `*.xlsx` files and outputs `*_FILTERED.csv`).

### 2. Helping the User Configure Search & Localization
When the user wants to search in a different city or filter a different language:
- Modify [`config.py`](file:///c:/Users/haker/Downloads/JobSpy_fork/config.py):
  - `LOCATION = "City, Country"` (e.g. `"Madrid, Spain"` or `"London, UK"`).
  - `COUNTRY_INDEED = "spain"` / `"uk"` / `"usa"` / `"germany"`.
  - `ACTIVE_LANGUAGE_PATTERNS = SPANISH_REGEX_PATTERNS` (or `GERMAN_REGEX_PATTERNS` / `FRENCH_REGEX_PATTERNS` / `[]`).
  - `SEARCH_CATEGORIES = {...}` (define target categories and query keywords).
  - `PROFILE_KEYWORDS = [...]` (update candidate target keywords for match scoring).

### 3. Helping the User Customize their Master CV & Typst Layout
- **Updating Experience:** Edit [`Master_CV.md`](file:///c:/Users/haker/Downloads/JobSpy_fork/Master_CV.md). Keep Section 3 (Experience Bank) structured with clear bullet points, and Section 5 (Keyword Translation Matrix) updated.
- **Updating Resume Header/Static Sections:** Edit [`main.typ`](file:///c:/Users/haker/Downloads/JobSpy_fork/main.typ).
  - Header contacts are in lines 30–42.
  - Margins and paper sizes are in lines 7–10.
  - Font family is configured on line 13 (`"Liberation Sans"` or `"Arial"`).

### 4. Troubleshooting Common Issues
- **`openpyxl` / `streamlit` Missing:** Run `pip install -r requirements.txt`.
- **`typst` Command Not Found:** Verify Typst CLI installation (`winget install --id Typst.Typst` on Windows, `brew install typst` on macOS).
- **Gemini API Key:** Ensure user sets `GEMINI_API_KEY` environment variable or enters it in the sidebar.
